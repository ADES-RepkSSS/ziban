# 字伴 v0.2.1 · 桌面取词完整版

发布日期：2026-10-23

这是 v0.2 的补丁完整版：主要补上“网页演示版没有屏幕取词”的明确标注，并把 Windows 免安装绿色版作为 Release 附件发布。

## 下载

- **Windows 绿色版（推荐）**：下载 `ziban-win32-x64.zip`，解压后双击 `Ziban.exe` 或 `启动字伴.cmd`；免安装，不需要管理员。
- macOS：暂未提供 `.app`/DMG；需要在 Mac 上用 Xcode/签名工具构建，见 [docs/09](../09-deploy-and-use.md)。
- 源码：本 Release 自动附带 GitHub 源码包。

> Windows 版未签名，SmartScreen 可能提示“未知发布者”；这是开发版，不是正式签名安装包。

## 这一版有什么

- **Windows 光标跟随取词**：鼠标停在哪，小窗显示词、拼音、口语释义、例句、来源和风险提示。
- **整词取词**：词表 + `Intl.Segmenter`；“今天很暖和”取“暖和”，不会只取“暖”。
- **自适应截图**：按显示器分辨率和缩放计算，约 260–420 DIP 宽。
- **小窗语音修复**：鼠标进入小窗时激活；`speechSynthesis.resume()`；播放时显示“正在念”，失败有提示。
- **首页看图找工具**：看屏幕、每天三个字、看图找字、帮我看屏幕。
- **版本检查**：启动 3 秒后只读 GitHub 公共版本信息；有新版本只给链接，不自动下载/安装。
- **网页演示明确标注**：首页“看屏幕上的字”卡显示“网页演示版 · 没有屏幕取词”，只能粘贴文字。
- **语料库交接**：[docs/10](../10-corpus-handoff.md) 与 `pnpm corpus:validate`。

## 已验证

- Windows 11 / 2560×1600 / 200%：OCR、真实截屏取词、光标跟随、小窗、打包版启动与 OCR 冒烟通过。
- `pnpm check`：60 个测试通过。
- macOS CI：Vision helper 编译与测试图识别通过；**真机 TCC/Retina/全屏/双屏仍未验收**。
- GitHub Pages：网页演示自动部署成功。

## 已知限制

- 没有 macOS DMG、Windows NSIS 安装包、代码签名、自动更新。
- 50 张卡仍是 `draft`，未走正式内容审校。
- 大模型默认关闭；语料库第一版制作中。
- 屏幕取词依赖系统中文 OCR 语言包；锁屏/黑屏会提示“屏幕锁着”。
- 网页演示没有屏幕取词，不能读取其他软件。

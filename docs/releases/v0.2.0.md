# 字伴 v0.2.0 · 桌面取词实验版

发布日期：2026-10-23

这是字伴第一个可以把“光标停在字上，小窗告诉你读音/释义/例句”真正跑起来的桌面版本。仍然是实验版：内容未审校、macOS 未真机验收、没有安装包和签名。

## 这一版能做什么

- **光标跟随取词**：打开“看屏幕”后，光标停稳约 380ms，只截光标周围小区域；不用框选、不用复制。
- **整词取词**：词表最长匹配 → `Intl.Segmenter` 中文分词 → 最后才单字；“今天很暖和”会取“暖和”，不是“暖”。
- **自适应截图**：按当前显示器工作区/缩放计算（约 260–420 DIP 宽），不再写死 340×180。
- **小窗讲解**：词、拼音、口语释义、生活例句、来源、风险提示；自动念“词 + 释义”，可点“念”重听。
- **Windows OCR**：常驻 PowerShell + `System.Drawing` + WinRT `Windows.Media.Ocr`，不需要额外权限。
- **macOS 代码路径**：`screencapture` + Apple Vision；只需屏幕录制权限；**待真机验收**。
- **知识管线**：50 张字卡 > `userData/corpus` 语料库 > 本机词表 > 可选大模型；默认离线。
- **首页重做**：第一入口是“看屏幕上的字”，下面是带特征图的“每天三个字 / 看图找字 / 帮我看屏幕”。
- **版本检查**：启动 3 秒后只读 GitHub 公共版本信息；有新版本只提示并给链接，不自动下载/安装；可在设置关闭。
- **Windows 绿色版**：`pnpm desktop:package` 生成 `release/ziban-win32-x64/Ziban.exe` 和 zip；未签名。

## 已验证

- Windows 11、2560×1600、200% 缩放。
- `desktop:ocr-smoke`：识别“医院挂号在二楼窗口 / 验证码不要告诉别人 / 今天很暖和”，整词断言 `暖和`。
- `desktop:lookup-smoke`：真实截屏取词目标“验证码”，整条链路约 52ms。
- `desktop:hover-smoke`：小窗出现，目标“验证码”。
- `desktop:ui-smoke`：400×517 DIP 小窗正常渲染。
- `pnpm check`：60 个测试通过。
- 打包后的 `Ziban.exe` 启动、首页、OCR smoke 验证通过。

## 已知限制

- **macOS 未真机验收**：TCC、Retina 坐标、全屏/双屏仍需在 Mac 上跑 [docs/08](../08-screen-lookup.md) 第 6.6 节。
- 没有 macOS DMG、Windows NSIS 安装包、代码签名、自动更新。
- 50 张卡仍是 `draft`，未经 C5 对抗审校与人工审校。
- 大模型默认关闭；语料库第一版仍在制作中。
- 屏幕取词依赖系统中文 OCR 语言包；锁屏/黑屏会提示“屏幕锁着”。

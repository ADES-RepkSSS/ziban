# OCR fixtures

`ocr-sample.png` is generated by the Ziban project for cross-platform OCR smoke tests.
Text is project-authored (`self`), not copied from a dictionary or corpus. The image is
licensed CC BY-SA 4.0 together with the project content; no personal data.

Text includes `医院挂号在二楼窗口`、`验证码不要告诉别人` 和 `今天很暖和`。
`desktop:ocr-smoke` 除了检查 OCR 是否出字，还会把光标放在“暖”上，
断言取词结果是整词“暖和”，防止退化成单字“暖”。

It is used by:

- `pnpm desktop:ocr-smoke` (Windows WinRT / macOS Vision)
- `.github/workflows/desktop-macos.yml` (direct Vision helper test)

Do not replace it with a screenshot of a real person's screen or real banking/medical
information. Add synthetic text only.
